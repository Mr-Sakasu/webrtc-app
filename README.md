# WebRTC P2P Test

最大6人で映像と音声を共有するシンプルな WebRTC アプリです。参加者ごとに1対1の P2P 接続を作り、全員をそれぞれのカードに表示します。

ページを開いた時点ではカメラとマイクはオフです。「カメラをオン」「マイクをオン」を押したときだけ利用許可を求めます。それぞれのボタンで後からオン・オフを切り替えられます。画面共有は1人でも開始でき、後から相手が参加すると共有中の画面を送ります。
チャット欄では同じルームの全員とメッセージを交換できます。メッセージの履歴は保存されません。
Markdown の強調・リンク・コードなどを書けます。TeX 数式は `$x^2$`（行内）や `$$x^2$$`（別行）で入力できます。複数行の数式は `$$` で囲んでください。

```bash
npm ci
npm start
```

ブラウザで `http://localhost:3000` を開いてください。複数人で接続する場合は、それぞれのブラウザで同じページを開きます。

映像は参加者同士の WebRTC 接続で送り、参加や接続の連絡とチャットには Socket.IO サーバーを使います。
